## Keputusan desain
- Batas "tercapai" (>=) sudah mem-pause, supaya run ke-7 tidak sempat mulai.
- Run yang masih berjalan dihitung durasinya sampai sekarang; hari dihitung WIB (offset di limits.json).
- Hitungan dari riwayat run host, bukan payload event (bentuk payload tidak diverifikasi).
- Idempoten: agent yang sudah paused tidak diaudit ulang. Nilai batas tidak valid melempar galat, bukan diam-diam longgar. Galat guard dicatat sebagai error di log plugin.
- Plugin tetap generik: path file batas lewat config plugin `limitsFile` atau env `AAO_LIMITS_FILE`; tanpa itu default 6/60.

## Yang tidak bisa diverifikasi sekarang
- Pause nyata oleh event run sungguhan: butuh run agent berbayar; dibuktikan di E1.2 (guard aktif).
- `limitsFile` belum disetel di config plugin pada server; saat ini guard memakai default yang kebetulan sama dengan limits.json EdukasiAI. Penyetelan config per company dicatat sebagai tindak lanjut di E1.1/F1.1 ulang.
- Endpoint `heartbeat-runs?limit=500` hanya diuji pada bentuk respons yang terlihat (array dengan agentId/startedAt/finishedAt).
