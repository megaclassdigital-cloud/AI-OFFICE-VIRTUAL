| Teks melebihi batas slot | exit 2, pesan "127 karakter, melebihi batas 90" + "TIDAK dipotong", 0 PNG (AC1.6) |

| `install-division --dry-run`, company ada | merencanakan 5 agent; **tidak ada** POST/PATCH/PUT/DELETE yang sampai ke server |
| `--dry-run`, company belum ada | merencanakan membuat company; tetap tanpa perubahan |
| `--dry-run`, agent sudah ada | "MEMPERBARUI", `dibuat=0` (idempoten) |
| Server belum siap / mati / manifest tak ada | exit 1, pesan jelas, tidak menggantung |

Server tiruan mencatat setiap request, sehingga klaim "dry-run tidak mengubah apa pun" dibuktikan dari sisi server, bukan dari output skrip sendiri.

## Yang tidak bisa diverifikasi dan alasannya

- Test render **tidak** merender PNG sungguhan (semua kasus gagal di validasi sebelum Chromium). Render nyata diuji di F1.8a.
- Test installer tidak memverifikasi mode non-dry-run (membuat/memperbarui agent). Itu sudah dibuktikan terhadap Paperclip nyata di F1.1 dan akan diuji ulang di G1.

## Risiko atau asumsi baru

Kasus pertama test render memakan ~18 dtk karena Node dingin mengimpor Playwright di mesin 2 core (berikutnya 1–2 dtk). Timeout 120 dtk memberi ruang cukup.

`vitest@5.0.3` (devDependency, dipin). Alasan: diwajibkan DEFAULTS.md (test runner) dan BACKLOG F1.0a.
