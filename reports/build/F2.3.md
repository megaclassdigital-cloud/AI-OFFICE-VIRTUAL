# F2.3 — Reject loop

Tanggal 2026-10-08.

## Yang dibuat
`scripts/owner-decide.mjs` (`decide`, `httpClient`; CLI `approve|reject`). Dijalankan owner; token dibaca dari `.env`, tidak lewat argumen.
- **reject**: catatan wajib (ditolak sebelum menyentuh apa pun bila kosong). Record ditulis dulu, lalu komentar berisi catatan owner ke issue, lalu issue dikembalikan ke Copywriter (`in_progress`, assignee Copywriter). Bila agent Copywriter tidak ada, dibatalkan sebelum record ditulis.
- **approve**: record approved terikat hash paket nyata (dari dokumen issue + PNG di disk), komentar, status `done`. Tidak memposting; paket dibuat oleh `prepare-publication.mjs`.
- Hanya issue `in_review` yang dapat diputuskan; transisi dicek ke `lifecycle.js` (aktor owner).

## Bukti
`tests/owner-decide.test.mjs` (6 tes): reject tanpa catatan (kosong/spasi) ditolak tanpa efek; reject valid menulis record + komentar memuat catatan + update ke Copywriter; token salah tidak menghasilkan record/komentar/perubahan; issue bukan in_review ditolak; tanpa Copywriter dibatalkan sebelum record; approve menghasilkan record bertaut hash dan status done.

## Batas
Diuji dengan klien palsu; `httpClient` belum dijalankan terhadap Paperclip nyata (butuh issue in_review nyata; menunggu E1.2). Counter putaran QA di state plugin tidak di-reset saat reject; QA berikutnya tetap mengikuti batas 2 putaran per jalur (catatan untuk E1.2).
