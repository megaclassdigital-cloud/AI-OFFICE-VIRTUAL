# F2.5 — Laporan KPI mingguan

Tanggal 2026-10-08.

## Yang dibuat
`scripts/kpi-report.mjs` -> `reports/kpi/kpi-YYYY-Www.md` (`--week`, default minggu ini; minggu ISO, Senin 00:00 WIB). Hanya membaca: GET Paperclip dan berkas lokal (`output/approvals`, `output/audit.log`, `workspace/issues/*/render/visual-qa.json`).
Tujuh KPI PRD bagian 1, masing-masing dengan angka dan status `TERCAPAI | BELUM | BELUM ADA DATA`:
konsistensi (draf = issue yang mendapat dokumen `handoff` pada minggu itu, dibandingkan dengan minggu sebelumnya), akurasi sumber, lolos QA pertama kali (komentar `QA:` pertama per issue), biaya, publish tanpa approval (setiap `publish_prepared` harus punya record approved dengan issue + hash sama), waktu manusia (handoff -> keputusan owner), kualitas visual.
- Ledger uji AC0.5 (250 sen) dikecualikan dari biaya; angka mentah tetap ditampilkan.
- Karena `billed_cents` selalu 0, ditambah jumlah run, run gagal, durasi, dan token.
- KPI tanpa kejadian ditulis "belum ada data", bukan 0% atau lulus.

## Bukti
- `tests/kpi-report.test.mjs` (11 tes, data sintetis): batas minggu ISO, draf per minggu, akurasi sumber, QA pertama kali, pengecualian ledger uji (tidak negatif), publish tanpa approval, median waktu manusia, persen visual, rendering "BELUM ADA DATA" dan 7 baris KPI. Suite penuh 24 file lulus.
- Dijalankan sekali terhadap Paperclip nyata (GET saja): `reports/kpi/kpi-2026-W41.md`.
