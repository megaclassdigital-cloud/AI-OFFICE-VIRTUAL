# F2.1 — Approval record khusus owner

Tanggal 2026-10-08.

## Yang dibuat
- `scripts/owner-approval.mjs`: `initOwnerToken` (AAO_OWNER_TOKEN 64 hex di `.env`, gitignored), `recordDecision`, `readDecisions`, `latestDecision`.
- Otoritas = token owner lokal (perbandingan timing-safe, minimal 32 karakter). Token tidak pernah dikirim ke agent; plugin tidak mengimpor modul ini dan tidak punya tool approve/reject.
- Record divalidasi terhadap `schemas/approval-record.json`, ditulis satu berkas per keputusan di `output/approvals/<issueId>/` dengan flag `wx` (tidak menimpa). Reject wajib catatan tidak kosong. Berkas rusak/dipalsukan diabaikan saat dibaca.

## Bukti
`tests/owner-approval.test.mjs` (9 tes): token salah/kosong/pendek ditolak tanpa menulis; tanpa token terkonfigurasi ditolak; reject tanpa catatan ditolak; hash/enum tidak valid ditolak; append-only; berkas palsu (`decided_by: agent`, issue lain, JSON rusak) diabaikan; tidak ada tool plugin bernama approve/reject/publish/token dan sumber plugin tidak menyebut owner-approval atau AAO_OWNER_TOKEN.

## Batas
Pemanggil (Console/skrip owner di F2.2+) wajib menghitung hash dari paket nyata; mengikat record ke paket saat ini diverifikasi di F2.2. Belum ada tombol approve di UI (O-005 bila owner ingin tombol di Console).
