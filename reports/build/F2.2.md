# F2.2 — prepare_publication

Tanggal 2026-10-08.

## Yang dibuat
`scripts/prepare-publication.mjs` (`preparePublication`, `currentPackageHash`, `slugify`). Dijalankan owner/Console, bukan tool agent.
- Syarat: keputusan TERAKHIR owner `approved` dan hash paket saat ini (carousel + design + hash semua `slide-*.png` dari disk) sama dengan hash di record.
- Output: `output/edukasiai/<tanggal WIB>-<slug>/` berisi `slide-NN.png`, `slides.md`, `caption.txt`, `sources.md`, `meta.json`. Ditulis ke folder sementara lalu di-rename (tidak ada paket setengah jadi).
- Idempoten: issue + hash yang sama menemukan folder yang ada (meta.json), tidak membuat folder kedua. Approval baru dengan hash baru membuat folder baru, folder lama tidak ditimpa.
- Setiap percobaan masuk `output/audit.log` (JSON per baris): `publish_prepared`, `publish_idempotent`, `publish_refused_no_approval`, `publish_refused_not_approved`, `publish_refused_hash_mismatch`.
- Tidak memposting apa pun.

## Bukti

Suite penuh 21 file, 290 tes lulus.
