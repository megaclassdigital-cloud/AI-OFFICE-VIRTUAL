# F2.4 — Routine harian (nonaktif secara default)

Tanggal 2026-10-08.

## Temuan
Paperclip 2026.1001.0 punya API routine: `POST /companies/:id/routines`, `POST /routines/:id/triggers`, `PATCH /routine-triggers/:id`; status `active|paused|archived`; `concurrencyPolicy` `coalesce_if_active|always_enqueue|skip_if_active`; `catchUpPolicy` `skip_missed|enqueue_missed_with_cap`. Daftar routine company EdukasiAI saat ini kosong (dicek lewat GET).

## Yang dibuat
`scripts/install-routine.mjs` (`buildRoutineSpec`, `installRoutine`, CLI `--enable|--disable`):
- Routine `paused` + trigger jadwal `enabled:false`, cron `0 7 * * 1-5`, zona `Asia/Jakarta`, ditugaskan ke Researcher di project "Carousel Berita AI".
- Anti duplikat: `skip_if_active` (pemicu saat run/issue sebelumnya masih aktif dilewati), `skip_missed`, dan installer idempoten (dicari lewat judul; lebih dari satu = berhenti, minta owner merapikan).
- Pemasangan ulang tanpa flag tidak mengubah routine yang sudah diaktifkan owner.
- Skrip tidak pernah memanggil endpoint run/fire.
- Tunduk pada guard F1.0f lewat plugin (batas di `divisions/edukasiai/limits.json`); deskripsi routine menyuruh agent berhenti bila batas tercapai.

## Bukti
`tests/install-routine.test.mjs` (11 tes, klien palsu): default nonaktif, cron/zona, kebijakan anti duplikat, pasang 3x = 1 routine + 1 trigger, enable/disable, duplikat ditolak, sumber tidak memuat /run atau /fire. Suite penuh 23 file, 307 tes lulus.

## Belum terbukti
- Pemicu dua kali menghasilkan satu issue di Paperclip nyata: hanya kebijakan `skip_if_active` yang diset; perilakunya di server tidak diuji karena memicu routine = run agent LLM (butuh izin O-004).
- Routine belum dipasang di Paperclip nyata (O-005: konfigurasi permanen, menunggu owner).
