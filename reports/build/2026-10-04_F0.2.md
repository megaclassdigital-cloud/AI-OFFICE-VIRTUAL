## Masalah nyata yang ditemukan

### Agent terjebak loop setelah pekerjaannya selesai

Log NDJSON run menunjukkan agent mengulang perintah `tool_call` yang **identik** belasan kali dalam 2 detik, semuanya PowerShell:

```
{"type":"acpx.tool_call","name":"$apiBase = $env:PAPERCLIP_API_URL...; $headers = @{ Authorization = \"***REDACTED***\"; ... };
 $body = @{ body = 'Riset selesai: enam kandidat berita AI...' }"}
```

Yang penting: **komentarnya sebenarnya sudah berhasil** (ada tepat 1 komentar, timestamp 16:26:56.053, dan `completedAt` issue 16:26:56.445). Jadi agent mengulang sesuatu yang sudah sukses.

Penyebab kemungkinan besar sama dengan bug yang saya temukan di F0.3: agent memakai `Invoke-RestMethod` PowerShell untuk mengirim body berisi teks Indonesia dengan backtick dan karakter non-ASCII. Perintahnya menggantung dari sudut pandang agent, jadi ia mencoba lagi, padahal server sudah menerimanya.

Dampak: token terbakar sia-sia setelah pekerjaan selesai. Run kedua (`d3280774`) saya hentikan manual lewat `POST /api/heartbeat-runs/<id>/cancel`; setelah itu 0 proses codex tersisa.

Ini **harus** diselesaikan sebelum Fase 1, karena pipeline punya 5 agent dan loop seperti ini akan berlipat.

### Satu issue memicu dua run

Membuat issue sudah otomatis memicu heartbeat. Perintah `heartbeat:invoke` manual menambah run kedua untuk agent yang sama. Perlu diingat agar tidak menjalankan pekerjaan ganda, dan relevan untuk skenario "Duplikat" di PRD.

### Log server sempat berada di dalam cwd agent

`start-paperclip.ps1` menulis log ke `workspace/`, yang sempat juga menjadi cwd agent — artinya agent bisa membaca/menimpa log server. Sudah diperbaiki dengan memindahkan cwd agent ke `workspace/agent`.

## Yang tidak bisa diverifikasi dan alasannya

- **Kebenaran isi riset** — URL terlihat nyata dan formatnya benar, tetapi **belum diverifikasi** bahwa URL benar-benar bisa dibuka dan tanggalnya tepat. Itu justru tugas Verifier (F1.3) dan sengaja tidak saya kerjakan di sini.
- **Kepatuhan penuh pada instruksi** — agent memakai 6 kandidat (sesuai), tetapi belum diuji apakah ia menolak instruksi injeksi dari halaman web. Skenario prompt injection ada di PRD dan belum dijalankan.
- **AC0.3 (isolasi)**, **AC0.4 (plugin)**, **AC0.5 (budget)** — di luar cakupan F0.2.
- **Biaya sebenarnya dalam rupiah/dolar** — Paperclip menandai `unpriced` karena memakai langganan. Tidak ada angka biaya per-run yang bisa dilaporkan selain USD 0 tambahan.

## Risiko atau asumsi baru

1. **Loop agent membakar kuota.** Masalah terbesar dari run ini. Harus diperbaiki sebelum pipeline 5 agent dijalankan. Kandidat solusi: beri agent tool/skill deterministik untuk mengirim komentar (lewat plugin `aao-approval-gate`) supaya tidak menyusun perintah HTTP PowerShell sendiri.
2. **`subscription_included` bukan benar-benar "gratis".** Biaya API memang USD 0, tetapi pemakaian membebani langganan ChatGPT owner dan bisa kena rate limit. KPI "biaya ≤ USD 5/bulan" terpenuhi secara harfiah, tetapi asumsi PRD soal model gratis tetap belum terbukti.
3. **Agent menulis file bebas di cwd-nya.** Sudah dibatasi ke `workspace/agent`, tetapi di dalam folder itu agent bebas. Belum ada validasi skema terhadap `research-output.json` — saat ini hanya kebetulan formatnya benar. F1.2 harus menambahkan validasi deterministik.
4. **Nama file output ditentukan agent, bukan kontrak.** Agent memilih `research-output.json` sendiri karena instruksi menyebut skemanya. Belum ada jaminan nama/lokasi file. Perlu dikunci di F1.2.
