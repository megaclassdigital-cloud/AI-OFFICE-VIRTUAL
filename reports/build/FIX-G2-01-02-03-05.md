# FIX-G2-01, -02, -03, -05 — otoritas approval (temuan G2)

Tanggal 2026-10-08. Syarat G2 sebelum E1.2.

## Perubahan
- **G2-01** `scripts/owner-approval.mjs`: setiap record ditandatangani HMAC-SHA256 (kunci diturunkan dari `AAO_OWNER_TOKEN`) atas JSON kanonik; `readDecisions` hanya menerima record dengan tanda tangan sah dan, tanpa token, mengembalikan kosong (gagal tertutup). Berkas valid skema ber-`decided_by:"owner"` tanpa tanda tangan, dengan tanda tangan palsu, isi diubah, atau kunci lain, ditolak (pemalsuan yang dibuktikan reviewer kini gagal). Skema `approval-record.json` mendapat field `signature`.
- **G2-02** `scripts/owner-decide.mjs`: approve dan reject wajib ada dokumen `handoff` dengan hash yang sama dengan hash paket saat ini; tanpa handoff (QA belum lolos) atau setelah PNG/teks berubah, ditolak sebelum record ditulis. Folder render diturunkan dari issue (`workspace/issues/<id>/render`), argumen `--render-dir` dihapus. `attach_file` menolak key `handoff` (hanya `handoff_to_owner` yang menulisnya; sekaligus menutup bagian key-overwrite FIX-G1-09).
- **G2-03**: `preparePublication` wajib `issueStatus === 'done'`; `decide` aman diulang: keputusan identik (jenis, hash, catatan) yang sudah tercatat dipakai ulang dan hanya langkah API yang dilanjutkan (tidak ada record kedua); catatan beda = keputusan baru.
- **G2-05** `render_carousel`: berkas design dibaca sebelum render; segel dibuat dari isi itu, dan tidak dibuat bila berkas berubah selama render atau hash PNG di disk beda dari laporan renderer (`sealed:false`, `passed:false`).
- Manifest disinkronkan.

## Bukti
Suite penuh 24 file, 332 tes lulus (sebelumnya 318). Tes baru: tanda tangan (3), publish ditolak untuk issue belum done dan untuk record palsu, decide tanpa handoff / PNG ditukar setelah handoff / handoff tanpa hash, kegagalan API di tengah approve dan reject (resume tanpa record kedua), `attach_file` key handoff ditolak, segel render lewat handler (6 PNG, hash design cocok).

## Belum terbukti (jangan dianggap selesai)

Belum ada bukti bahwa agent nyata tidak bisa membaca `.env`, menulis `output/approvals`, atau menjalankan `owner-decide`.
