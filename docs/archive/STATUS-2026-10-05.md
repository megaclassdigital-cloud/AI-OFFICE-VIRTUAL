1. **Komunikasi agent masih lewat PowerShell buatan agent sendiri.** Loop sudah ditekan dengan `timeoutSec` + protokol, tetapi akar masalahnya belum hilang. Perbaikan tahan: tool komentar/status deterministik di plugin `aao-approval-gate`, sehingga agent tidak pernah menyusun HTTP sendiri.

2. **Belum jelas siapa yang menutup issue.** EDU-2 tetap `in_progress` setelah agent selesai; Paperclip memunculkan "needs a disposition" dan memicu heartbeat baru terus-menerus.

3. **Perlindungan biaya tidak berfungsi.** Metrik budget `billed_cents` selalu 0 dengan adapter langganan, jadi hard stop tidak akan pernah menyala oleh pemakaian nyata. Batas harus dipindah ke jumlah run / durasi / token.

## Catatan penting untuk sesi berikutnya

1. **Paperclip di `http://127.0.0.1:3177`** (bukan 3100 — itu milik ERP-KIOS owner).
2. **Menjalankan server:** `.\scripts\start-paperclip.ps1` (detached). Tidak ada Windows service, tidak auto-start setelah reboot.
3. **Memasang/memperbarui division:** `node scripts/install-division.mjs` (idempoten, terbukti 5× berturut-turut).
4. **Jangan pakai `Invoke-RestMethod` PowerShell untuk POST berisi teks Indonesia panjang** — menggantung selamanya (Content-Length vs byte UTF-8). Pakai Node `fetch` dengan `Buffer.byteLength`, atau `curl.exe --data-binary "@file"`.
5. **Plugin wajib pakai pola `startWorkerRpcHost`**, bukan `runWorker()` — deteksi main-module SDK gagal di Windows ini.
6. **Pin versi:** `paperclipai@2026.1001.0`, `playwright@1.56.0`, Chromium 1194.
