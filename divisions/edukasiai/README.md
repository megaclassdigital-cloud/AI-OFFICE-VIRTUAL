# Division: EdukasiAI

Brand dan operating unit untuk konten edukasi/berita AI. Proof of concept pertama AI Agent Office.

Pipeline MVP: Researcher → Verifier → Copywriter → Designer → Renderer (kode) → QA → Approval owner → paket publikasi.

| Folder | Isi |
| --- | --- |
| `agents/` | Definisi dan instruksi 5 agent (bahasa Indonesia) |
| `sop/` | SOP produksi carousel, checklist QA teks dan visual |
| `brand/` | `brand.json`, `templates.json`, `templates/` (HTML/CSS), `fonts/`, `icons/` |

Dipasang ke Paperclip dengan `scripts/install-division` (idempoten, F1.1).
